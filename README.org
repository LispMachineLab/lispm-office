#+title: LispM Office

A living office of LispM agents, inside Emacs. Each live conversation has a desk;
rooms group projects, and an inspector shows what an agent is doing and what is
in its mailbox. Works in graphical Emacs and on a text terminal.

* Using it

=M-x lispm-office= opens the live office. Click a desk or press =RET= to inspect
its Work, Mailbox or Character. The waiting strip and =n= lead to agents that need
you. Rooms grow automatically, with a map overview when there are many agents.
Seats survive restarts; only =Compact Saved Seats…= removes empty reservations.

=M-x lispm-office-demo= opens twelve simulated agents without starting or messaging
anything. =C-u M-x lispm-office-demo= asks for a count from 2 to 1000. Preview
agents cannot perform actions and do not change saved seats.

| Key             | Action                                      |
|-----------------+---------------------------------------------|
| Arrows / C-b/f/p/n | Select a nearby desk                      |
| n / TAB         | Select the next waiting agent               |
| RET             | Inspect the selected conversation           |
| w / m / c       | Work / Mailbox / Character                  |
| o / s           | Open chat / compose a message               |
| a / d           | Approve / deny one pending permission       |
| A               | Preview and approve this agent’s pending calls |
| x               | Confirm stopping this agent and clearing its queue |
| + / - / 0       | Zoom in / out / fit                         |
| h / r           | All rooms / choose a room                   |
| t               | Toggle text view                            |
| g / q           | Refresh / close and release subscriptions   |

Approve All is limited to one selected agent and its current turn. A change to
the displayed permissions cancels the preview. Terminal agents expose only the
actions supported by their provider; open their chat for questions or approvals.

* Installing

Requires Emacs 30.1+, LispM Kit 0.2.0+, LispM UI 0.5.0+ and LispM Agent with the
roster API from [[https://github.com/LispMachineLab/lispm-agent/pull/135][PR #135]]. Until that dependency is merged and released,
use its =agents-roster= branch for live data. The preview needs only Kit and UI.

With the dependencies already on =load-path=, add this checkout:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/lispm-office")
(require 'lispm-office)
(lispm-office)
#+end_src

After the dependency is available through your package setup, install the package
with =package-vc-install= from this repository. App Store catalog registration is
pending review and release of the roster dependency.

Seats are kept in =office-seats.eld= under =lispm-directory=; set
=lispm-office-seat-file= to use another file. =lispm-office-animate= disables
animation. The view does not poll agents and stops its timer while hidden or idle.

* Development

With sibling checkouts of LispM Kit and LispM UI:

#+begin_src sh
make test compile LISPM_AGENT=/path/to/agent-with-roster/lisp
#+end_src

=EMACS=, =LISPM_KIT= and =LISPM_UI= select other binaries or checkouts.
Integration tests use synthetic conversations with the real roster API; network,
model and tool execution are forbidden. Tests cover persistent layout, large
rosters, input handling, stale approvals, mailbox reads and observer/timer cleanup.
Compilation treats warnings as errors. [[file:docs/design.md][Design notes]] describe the data contract.
